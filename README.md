# Students Performance Dataset - Initial Data Exploration

## 📌 Overview
This project performs an initial Exploratory Data Analysis (EDA) on the **Students Performance Dataset** using Python and Pandas. The goal is to analyze the dataset's structure, check for missing values, inspect data types, and review summary statistics of student performance scores.

---

## 📁 Project Structure
* `StudentsPerformance.csv` - The target dataset containing student demographics and exam scores.
* `explore_students.py` / `data_explorer.ipynb` - Python script/notebook used to run the data analysis.
* `README.md` - Documentation of the project setup and execution steps.
